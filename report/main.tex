\section{Introduction and motivation}
Can information available after today's close predict the standard deviation of
SPY's daily returns over the next five trading sessions better than a recent
historical-volatility benchmark?

This is volatility regression: the object of interest is return variability,
rather than the price level or price direction. Forecasting variability can
inform risk measurement; accuracy must be demonstrated on a defined sample and
cannot be inferred from model complexity. This study does not evaluate a trading strategy.

SPY seeks to track the S\&P 500's price and yield performance before expenses
\cite{spy}. One broad equity instrument keeps the semester study manageable
while retaining substantial return variation. These instrument properties
motivate the case study; they do not establish forecasting performance.

\section{Related research}
\textbf{Measurement.} Standard deviation summarizes spread in observation units.
Squaring deviations gives extremes substantial influence \cite{nist}. The
five-return target is interpretable but noisy; it does not directly measure
latent conditional volatility. This limitation exists regardless of the algorithm.

\textbf{Multiple horizons.} Corsi's HAR-RV framework combines volatility
components at different horizons \cite{corsi}. It motivates short and longer
historical windows. Our 5-, 10-, and 20-session standard deviations of daily
returns are not a canonical HAR-RV replication or intraday realized variance.

\textbf{Statistical and machine-learning comparisons.} Breiman's Random Forests
combine randomized tree predictors \cite{breiman}, motivating a nonlinear
comparison with regularized linear regression. Christensen, Siggaard, and Veliyev
compare machine-learning and HAR models for realized variance \cite{christensen}.
Their measurement and application differ from this five-daily-return SD target;
their gains cannot be transferred to the present SPY sample.

\textbf{Temporal evaluation.} Scikit-learn distinguishes ordered forecast
evaluation from random folds \cite{cv,temporal_api}. Its row-count gap cannot
replace actual target-end checks when reserved rows create irregular spacing.
The annual folds and bounded search grid below are project choices recorded
before scoring, not prescriptions attributed to these sources.

\subsection{Definitions and after-close information}
Let $P_t$ be adjusted close at original trading session $t$, and
$r_t=\log(P_t/P_{t-1})$. Forecasting occurs after session $t$ closes, so $r_t$ is
available. Stored model values are decimals: $0.01=1\%$.

\par

For $n$ returns $u_1,\ldots,u_n$, sample SD is
$s=\sqrt{\sum_{j=1}^n(u_j-\bar u)^2/(n-1)}$. Deviations measure distance from
the mean; squares avoid cancellation and emphasize extremes. The $n-1$
denominator is the sample-variance convention; the square root restores return
units. It does not make sample SD unbiased for population SD. Every window uses
\code{ddof=1}. Specifically,
\[
\bar r_{t,+}=\frac15\sum_{j=1}^5r_{t+j},\qquad
 y_t=\sqrt{\frac14\sum_{j=1}^5(r_{t+j}-\bar r_{t,+})^2}.
\]
The response is daily-return variability within five future sessions, not
annualized volatility or the SD of cumulative five-day returns. Calculating SD
requires no normality assumption; five observations make it noisy and sensitive
to extremes.

The benchmark predicts $\hat y_t=\mathrm{volatility\_20}_t$. All fitted models
use identical permitted rows and the predictor allowlist.

These mechanisms match the pinned implementation \cite{ridge_api,forest_api,boosting_api}.
A prespecified zero floor follows prediction; \FloorCount{} pooled validation
predictions required it. The pooled run uses scikit-learn \SklearnVersion{};
versions and exact settings accompany each run. No search selected the original
pooled specifications.

Suitability concerns the continuous target, available information, structure,
dependence and error diagnostics. Normal predictors or response are not required
for Ridge point prediction or tree prediction. Gaussian assumptions concern some
inference procedures, not permission to forecast. Ridge supplies a regularized
linear reference; trees permit nonlinear structure but can miss sparse extremes.
No transformation is imposed simply to pass a normality test.

\subsection{Fitting, selection and evaluation}
For $e_i=100(\hat y_i-y_i)$, define
\[
\mathrm{MAE}=n^{-1}\sum|e_i|,\quad \mathrm{MSE}=n^{-1}\sum e_i^2,\quad
\mathrm{RMSE}=\sqrt{\mathrm{MSE}},\quad \mathrm{bias}=n^{-1}\sum e_i.
\]
MAE summarizes typical absolute error; RMSE gives large misses greater influence.
Bias describes direction but opposing errors can cancel. MAE, RMSE and bias use
daily-volatility percentage points (pp); MSE uses squared pp \cite{mse_api}.
MSE and RMSE rank identical rows and weights identically, not as independent
confirmations. Main scores remain MAE, RMSE and bias; saved MSE diagnostics use
full-precision predictions.

\textit{Hypothetical example:} target $0.010$, prediction $0.012$ gives $+0.2$ pp
error and $0.04$ squared pp squared error, not a stock-return forecast or a claim
of 20\% forecast accuracy. Fitting loss, inner RMSE selection and reported outer
metrics have separate roles. RMSE penalizes large misses in both directions,
not underprediction specifically.

\input{generated/development_discussion.tex}
\subsection{What remains uncertain}
Only five returns form each noisy response. Shared windows create dependence
even within temporal evaluation. Historical reuse and underlying-return overlap
remain after protected identities are removed. These prevent pristine
out-of-sample or ordinary iid significance claims. Lower mean error need not
mean reliable performance during large-volatility episodes. Internal checks do
not validate another vendor's prices or establish profitable trading.
